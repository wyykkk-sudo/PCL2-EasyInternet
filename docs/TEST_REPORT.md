## Minecraft 登录连接调查

使用不含用户令牌的无效诊断请求，在同一测试机访问 `api.minecraftservices.com/authentication/login_with_xbox`。系统 curl、PowerShell 7，以及 .NET Framework HttpClient 的 SystemDefault、TLS 1.2 和原 Windows 7 回退协议配置均成功建立连接并得到预期的 HTTP 401。这里的 401 来自刻意使用无效令牌，不代表用户登录被测通过。

该测试未复现用户操作时的 TLS 连接关闭，无法将其确定为协议版本问题。真实登录日志中的 403 无法独立区分应用资格、网络出口或其他服务拒绝原因。程序补充第 4 步网络故障提示，并将原先断言 IP 异常的 403 文案改为需要检查网络与应用资格；不修改认证请求、不切换到不受信任接口。修改后重新编译，尚未完成真实账号复测。
